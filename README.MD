# Projeto de Análise Bibliométrica e de Conteúdo: Impacto da IA na Investigação Científica

## Descrição do Projeto
Este projeto visa realizar uma análise bibliométrica e de conteúdo para avaliar o impacto da Inteligência Artificial (IA) na investigação científica. 

## Estrutura do Projeto
### Dados obtidos da Scopus
Em formato CSV:
    - scopus.csv
    - Scopus_Country.csv 
    - Scopus_Subject.csv

### Análise Bibliométrica
- Jupyter notebook: Analise_bibliometrica.ipynb

### Análise de Conteúdo
- Jupyter notebook: Analise_conteudo.ipynb

### Short paper
- Paper.pdf

### Dashboard
Realizado em streamlit: <a>https://icd2425-grupo9.streamlit.app/</a>
O dashboard é composto por:
- dashboard.py : a app principal
- bibliometrica.py: app complementar que tem funções e código em Python relativo à análise bibliométrica
- conteudo.py: app complementar que tem funções e código em Python relativo à análise de conteúdo e conclusão
- pasta "imgs": contém imagens de visualizações de dados para integrar no streamlit
- ficheiros csv que foram exportados do notebook de Análise de Conteúdos e trabalhados dentro do streamlit:
    - clustered_documents.csv
    - document_topic_distribution.csv
    - most_relevant_docs.csv

### Ambiente
 - projICD2425.yml
 - requirements.txt (necessário para o alojamento no streamlit cloud)
